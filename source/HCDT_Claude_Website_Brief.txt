클로드 작업 지시서 — HCDT 로고 컬러 탐색 및 SVG 다운로드 웹사이트

아래 요구사항과 첨부 파일을 바탕으로 실제로 작동하는 웹사이트를 구현해줘. 사용자는 컬러 시안을 비교하고, 원하는 색상과 로고 형식 및 적용 방식을 선택한 뒤 SVG를 다운로드할 수 있어야 해.

1. 첨부 자료와 역할

• N-FUD 2026_Logo_261012.ai: 로고 벡터, 영문 로고 3가지 형식, 원본 컬러 8개의 기준 파일.
• image(20261012-045418).png: 색상 하나를 여러 적용 방식으로 보여주는 미리보기 구성의 기준.
• image(20261012-045518).png: The Longest / Long / Short의 형태와 배치 기준.

AI 파일의 PDF 호환 영역을 확인했을 때, 2·3·4번째 페이지에 영문 로고 3종, 9~16번째 페이지에 컬러 시안 8개가 있어. 페이지 번호는 1부터 센 값이야. 실제 Illustrator 아트보드와 대조해 올바른 오브젝트를 사용해줘. 1번째 페이지의 수정 전 로고, 주황색 치수선과 안내 글자, 한국어 로고는 웹사이트 로고 자산에 포함하지 마.

2. 핵심 요구사항

• 서로 다른 컬러 시안 총 100개를 제공해줘.
• 원본 파일에 있는 8개를 반드시 포함하고, 신규 컬러 92개를 추가해줘. 100개에 원본 8개가 포함되는 구조야.
• 원본 8개 카드에는 정확히 ‘메인 컬러’라는 배지를 붙여줘. 신규 92개에는 ‘확장 컬러’라고 표시해줘.
• 여기서 ‘메인 컬러’는 원본 8개 시안을 구분하는 표시야. 각 시안 내부의 보라색과 다른 색상의 역할은 ‘기준 보라’와 ‘보조색’으로 구분해 혼동을 막아줘.
• 영문 로고만 제공해줘. 한글 로고는 필요 없어. 사이트의 안내와 버튼은 한국어로 작성해줘.
• 영문 로고 형식은 The Longest, Long, Short 세 가지야.
• 모든 컬러 시안에서 세 가지 로고 형식과 적용 방식을 미리보고 SVG로 다운로드할 수 있어야 해.

3. 원본 로고 보존

이 작업은 이미 완성된 로고를 보여주고 배포하는 사이트 구현이야. 로고를 새로 그리거나 비슷한 폰트로 재작성하지 마.

AI 원본의 벡터 패스를 직접 추출해 SVG 자산을 만들어줘. 영문 워드마크는 아웃라인 패스로 유지하고, 원본의 T·H·D 시각 보정, 글자 간격, 줄 간격, 심볼과 글자 사이 간격, 심볼 내부 모듈 배치 및 비율을 그대로 보존해줘. 심볼을 원이나 일반적인 도트 패턴으로 대체하지 마.

세 형식의 차이는 첨부된 이미지와 원본의 실제 배치를 기준으로 해줘.
• The Longest: 심볼 오른쪽에 전체 학과명이 배치된 가장 긴 가로형.
• Long: 심볼 오른쪽에 축약된 학과명이 배치된 가로형.
• Short: 심볼 아래에 H–C / D+T가 배치된 세로형.

명칭의 대시·플러스·철자와 줄바꿈도 벡터 원본을 따라줘. 웹폰트로 로고 텍스트를 재현하지 마. 안내용 D·B 치수 표시와 주황색 선은 로고의 일부가 아니므로 제외해줘.

AI 파일을 직접 처리할 수 없으면 PDF 호환 영역의 벡터를 변환해 사용해줘. 그래도 정확한 벡터 추출이 불가능하면 필요한 원본 SVG 자산을 구체적으로 알려줘. 스크린샷 트레이싱이나 임의 재제작으로 완성된 것처럼 처리하지 마.

4. 컬러 100개 구성

원본 8개의 순서는 파일의 시안 순서를 유지해줘. 화면상으로는 라임, 오렌지, 민트그린, 옐로, 피치, 핑크, 라이트블루, 아쿠아 계열이야. 이 색 이름은 식별용이고, 실제 값은 AI 원본에서 추출해줘. 스크린샷의 픽셀을 채집한 근삿값을 원본값이라고 표시하지 마.

원본이 CMYK 또는 별색이면 원본 색상 정보와 웹 미리보기용 sRGB 값을 구분해서 관리해줘. 사이트에는 웹에 실제로 사용하는 HEX 값을 표시하고, 원본 정보도 데이터에 보존해줘.

신규 92개는 원본과 같은 색상 적용 구조를 유지하면서 보조색을 확장하는 방식으로 구성해줘. 첨부 시안의 기준 보라를 유지하고, 다양한 색상 계열에서 조화로운 보조색을 선정해줘. 원본 8개의 보라가 실제로 다르면 각 원본값을 먼저 보존하고, 신규 시안에 적용할 기준을 정리해줘.

단순히 같은 색을 거의 비슷하게 바꿔서 개수를 채우지 마. 보라와의 구분, 심볼 내부 두 색의 구분, 흰 배경에서 워드마크의 가독성을 고려해줘. 파스텔과 선명한 색상을 적절히 섞되, 지나치게 옅어서 글자가 안 보이는 신규 시안은 피해주세요. 로고가 소형일 때도 확인해줘.

100개는 고정된 데이터로 관리해줘. 새로고침할 때 랜덤하게 바뀌면 안 돼. 시안별 고유 ID, 이름, 원본 여부, 기준 보라, 보조색, 적용 방식별 색상 매핑을 저장해줘. 시안 번호는 001~100으로 부여해줘. 적용 방식이나 로고 형식이 달라도 별도의 컬러 시안으로 세지 마.

5. 화면과 탐색 흐름

첫 화면에서 이 사이트가 로고 색상을 탐색하고 SVG를 받는 곳임을 바로 알 수 있게 해줘. 제목, 짧은 설명, ‘전체 100’, ‘메인 컬러 8’, ‘확장 컬러 92’ 필터를 제공해줘. 원본 8개를 먼저 배치하고 신규 92개를 이어서 배치해줘.

컬러 갤러리는 흰색 바탕의 카드 그리드로 구성해줘. 카드에는 대표 로고, 색상 번호와 이름, 보라·보조색 칩, 메인/확장 배지가 보여야 해. 상단에서 The Longest / Long / Short를 바꾸면 갤러리의 대표 로고도 같은 형식으로 바뀌게 해줘. 모바일에서는 카드가 한두 열로 자연스럽게 정리되어야 해.

카드를 선택하면 상세 패널 또는 상세 화면에서 선택한 컬러의 큰 미리보기를 보여줘. 데스크톱에서는 갤러리와 상세 패널을 함께 볼 수 있는 구성을 권장하고, 모바일에서는 전체 화면 상세 보기를 사용해줘. 선택 상태는 테두리와 텍스트로 표시해서 색만으로 구분하지 않게 해줘.

상세 화면에는 아래 내용이 있어야 해.
• 선택한 컬러의 이름, 번호, 메인/확장 표시.
• 세 가지 형식 선택 버튼과, 세 형식을 함께 비교하는 미리보기.
• 첨부 2의 컬러 적용 방식 6개를 같은 구성으로 보여주는 미리보기 보드.
• 적용 방식 선택, SVG 다운로드 버튼.
• 색상 HEX와 복사 버튼.

6. 첨부 2 방식의 컬러 적용 미리보기

선택한 컬러를 단순한 색상 칩으로만 보여주지 말고, 첨부 image(20261012-045418).png처럼 실제 로고 사용 예시로 보여줘.

미리보기 보드는 왼쪽에 확대된 두 색 심볼, 오른쪽에 6개 적용 예시를 배치하는 구성을 기준으로 해줘. 배경색 띠는 시안 구분을 위한 화면 장식으로 사용할 수 있지만, 로고 SVG에 자동으로 포함하지 마.

6개 적용 방식은 다음과 같아. 최종 색상 배치는 AI 원본과 대조해서 맞춰줘.
① 흰 배경 / 두 색 심볼 / 보라 워드마크.
② 보라 배경 / 흰색·보조색 심볼 / 보조색 워드마크.
③ 보조색 배경 / 흰색·보라 심볼 / 보라 워드마크.
④ 흰 배경 / 두 색 심볼 / 보조색 워드마크.
⑤ 흰 배경 / 보라 단색 심볼·워드마크.
⑥ 흰 배경 / 보조색 단색 심볼·워드마크.

원본 심볼이 모듈별 두 색 배치로 구성되어 있으면 그 구조를 유지해줘. 실제 벡터에 그라데이션이 있을 때만 해당 그라데이션을 그대로 사용하고, 임의의 연속 그라데이션을 씌우지 마.

위 6개 적용 방식을 The Longest, Long, Short에 모두 적용해줘. 형식을 바꾸면 로고의 형태만 바뀌고 선택한 컬러와 적용 방식은 유지되게 해줘. 상세 화면의 세 형식 비교 영역에는 현재 선택한 적용 방식을 동일하게 적용해줘.

Short는 세로 비율을 유지해줘. 가로형과 같은 폭을 채우려고 과도하게 확대하지 말고, 동일한 미리보기 영역 안에서 형태를 비교하기 편한 크기로 배치해줘. 모든 로고의 종횡비를 유지하고 잘리지 않게 해줘.

7. SVG 다운로드

사용자가 선택한 컬러 × 형식 × 적용 방식이 다운로드 파일에 정확히 반영되어야 해. 전체 조합은 100 × 3 × 6 = 1,800가지야. 동일한 SVG 템플릿과 색상 데이터로 생성해도 돼.

다운로드는 다음 두 가지를 제공해줘.
• ‘SVG 다운로드’: 현재 선택한 형식과 적용 방식 1개.
• ‘3가지 형식 다운로드’: 현재 컬러·적용 방식의 The Longest, Long, Short를 ZIP으로 묶어서 다운로드.

기본 SVG는 투명 배경으로 내보내줘. 컬러 배경 적용 예시에는 ‘배경 포함’ 옵션을 제공하고, 켰을 때만 미리보기의 배경 사각형을 포함해줘. 투명 파일이라도 전경 색상은 선택한 적용 방식 그대로 유지해줘. 밝은 전경의 경우 파일명과 옵션 설명으로 사용 배경을 알아볼 수 있게 해줘. 흰 미리보기 바탕은 기본적으로 SVG에 넣지 마.

다운로드 SVG는 자체 완결적인 실제 벡터 파일이어야 해.
• 로고 글자는 아웃라인 path로 포함.
• raster image나 PNG를 SVG 안에 넣는 방식 금지.
• 외부 폰트, 외부 스타일시트, 외부 이미지, 외부 URL 참조 없이 열려야 함.
• 유효한 xmlns와 viewBox 사용, 비율 유지, 적절한 최소 여백 확보.
• 화면 버튼, 카드 배지, 치수선, 시안 번호는 포함하지 않음.
• 원본에 있는 clipPath나 gradient가 필요하면 SVG 내부 defs에 포함.
• 여러 SVG를 한 페이지에 렌더링할 때 ID가 충돌하지 않도록 처리.

파일명 예시:
HCDT_001_main_long_duotone-purple_transparent.svg
HCDT_001_main_short_reverse-on-purple_background.svg
HCDT_001_main_three-variants.zip

미리보기와 다운로드는 동일한 SVG 생성 로직을 사용해줘. 화면에는 맞는 색으로 보이지만 파일은 기본색으로 내려받아지는 오류가 없어야 해.

8. 디자인 및 구현 기준

로고와 컬러 비교가 중심이 되는 정돈된 디자인으로 만들어줘. 흰색 중심의 화면, 충분한 여백, 간결한 메뉴와 일관된 카드 구조를 사용해줘. 원본의 색을 정확하게 비교할 수 있도록 카드와 미리보기에 색조 필터나 불투명도 효과를 걸지 마.

React + TypeScript 등 적합한 웹 기술을 선택해 구현해줘. 로고 자산, 컬러 데이터, 렌더링·다운로드 로직을 분리해 유지보수하기 쉽게 구성해줘. 메인 8개의 원본 색상 매핑은 변경하지 않도록 별도로 보존해줘. 100개의 미리보기는 필요한 크기로 표시하고 과도한 DOM 복제와 지연을 피해주세요.

필터, 로고 형식 선택, 상세 보기, HEX 복사, SVG·ZIP 다운로드 버튼이 실제로 작동해야 해. 키보드로 선택과 다운로드가 가능해야 하고, 버튼에는 의미 있는 접근성 이름을 넣어줘. 로그인이나 관리자 페이지는 이번 범위에 필요 없어.

9. 구현 순서와 완료 기준

먼저 원본에서 세 형식의 SVG와 메인 8개의 색상 정보를 추출하고, 첨부 이미지와 나란히 비교해서 형태와 배치가 맞는지 확인해줘. 이후 메인 8개와 한 형식으로 미리보기·다운로드를 연결하고, 나머지 형식·적용 방식·92개 컬러를 확장해줘.

완료 전에 다음을 확인하고 결과를 알려줘.
□ 컬러 데이터가 중복 없이 정확히 100개이고 원본 8개+신규 92개로 구성됨.
□ 원본 8개에만 ‘메인 컬러’ 배지가 붙고 원본 순서가 유지됨.
□ 원본 8개의 색과 로고 형상이 AI 파일과 일치함.
□ 3종 로고의 배치, 시각 보정, 줄바꿈, 간격이 보존됨.
□ 100개 모두에서 3종 형식과 6개 적용 방식을 선택할 수 있음.
□ 미리보기와 다운로드 파일의 컬러·형식·적용 방식이 일치함.
□ 투명 배경과 배경 포함 옵션이 정확히 작동함.
□ SVG에 폰트 의존성·래스터 로고·외부 참조가 없음.
□ 선택한 시안의 3개 SVG가 ZIP에 정확히 포함됨.
□ 모바일에서도 로고와 버튼이 잘리지 않음.

전 조합의 생성 가능 여부와 SVG 구조는 자동으로 점검하고, 메인 8개×3형식의 형태·대표 적용 방식은 시각적으로 대조해줘. 다운로드한 SVG를 브라우저뿐 아니라 Illustrator 또는 동등한 벡터 도구에서도 열어 확인해줘. 해당 도구로 검증할 수 없으면 검증하지 못한 항목을 정확히 밝혀줘.

실행 가능한 프로젝트, 실행 방법, 원본에서 추출한 SVG 자산, 컬러 100개 데이터와 검증 결과를 전달해줘. 원본 벡터 확보에 막힌 사항은 임의로 추정하지 말고 구체적으로 알려줘.

사용자가 따로 제공해야 할 자료: 위 AI 파일과 PNG 참고 이미지 2개를 이 지시서와 함께 첨부해줘야 함. 지시서만으로 원본 벡터를 재현하지 않도록 해줘.
